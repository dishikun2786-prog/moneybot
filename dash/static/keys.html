Bybit 交易所 API

实盘交易用。密钥仅在绑定/测试/下单瞬间解密, AES-256-GCM 加密存储, 永不显示明文
① Bybit Secret 只显示一次, 请复制保存
② 套利策略需要同时勾选 现货交易 与 合约交易 权限
③ 若开启了 IP 白名单, 请加入服务器 IP
④ 只读密钥无法实盘, 绑定后会自动检测

Polymarket 账户

三选一绑定方式, 推荐「一次性私钥导入」(平台只保存派生交易凭证, 凭证不可提现)
⚠️ Owner 私钥是资金控制密钥（可提现全部资产）。平台设计：
① 私钥仅经 HTTPS 进入服务器内存一次, 用于派生 L2 交易凭证
② 派生完成后立即丢弃, 服务器只加密保存派生凭证（凭证只能下单/撤单, 不可提现）
③ 更安全的替代: 浏览器钱包签名连接（后续版本）, 私钥不出设备
