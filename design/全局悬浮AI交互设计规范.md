# AI 策略助手 · 全局悬浮交互设计规范

> v1.0 · 2026-09-25 · 基于 M-A/M-D/M-P 已上线功能的 UI 交互升级
> 目标：把 AI 助手从「独立页面」升级为「全局悬浮对话层」——任何页面一键唤起、切页对话不丢

---

## 一、交互架构（白话）

**现在**：AI 助手住在「AI 屏」里——用户要看 AI 得先切到那个页面，离开页面对话上下文就断了。
**升级后**：AI 助手以「悬浮按钮 + 半屏浮窗」形式住在 **App 全局层**——在所有页面（行情/交易/持仓/我的/托管中心）的右下角悬浮，点一下从底部滑出半屏对话窗，切到任何页面浮窗和对话都原样保留。

三层结构：

```
┌─────────────────────────┐
│  App 页面层（可切换）     │  ← 行情/交易/持仓/我的 正常切换
├─────────────────────────┤
│  全局 AI 层（常驻）      │  ← FAB 悬浮按钮（所有页面可见）
│  └ 半屏浮窗（按需展开）   │  ← 对话流 + 建议卡 + 输入栏
├─────────────────────────┤
│  底部菜单栏（常驻可点）   │  ← 浮窗展开时不被遮挡
└─────────────────────────┘
```

## 二、核心组件规范

### 2.1 FAB 悬浮按钮（常驻）

| 属性 | 值 |
|---|---|
| 位置 | 右下角，`right:16px`，底部距菜单栏 `12px`（bottom = 菜单栏高 + 12） |
| 尺寸 | 56×56px 圆形（拇指热区标准 ≥44px） |
| 视觉 | 品牌绿渐变 `135deg #4adea0 → #1f9d68`，白色 ✦ 图标 |
| 光效 | 呼吸光晕 2.6s 循环（阴影扩散 0→10px），`prefers-reduced-motion` 时禁用 |
| 未读徽标 | 红点 14px 右上角（有新建议/告警时显示，读后消失） |
| 展开时 | FAB 隐藏（`opacity:0 + pointer-events:none`，不占交互） |
| 按压 | `scale(.92)` 反馈 |

### 2.2 半屏浮窗

| 属性 | 值 |
|---|---|
| 位置 | 附着于菜单栏**上方**（`bottom:60px`），菜单栏全程可见可点 |
| 高度 | 峰值 **66% 屏高**（保持顶部页面可见，维持空间上下文） |
| 顶边 | 圆角 `20px 20px 0 0` + 抓手条（36×4px，暗示可下拉） |
| 入场动画 | `transform: translateY(105%)→0`，280ms `cubic-bezier(.32,.72,0,1)`（iOS 底滑节奏） |
| 遮罩 | `rgba(1,4,9,.55)` + 2px 背景模糊，淡入 250ms，点击关闭 |
| 结构（自上而下） | 抓手条 → 头部（状态点+名称+全屏按钮+关闭）→ 消息流（flex-1 滚动）→ 快捷 chips → 输入栏 |

**头部**：绿色呼吸状态点（Jev 在线）+ 名称 + 巡检频率小字（"5min 巡检"）+ ⤢ 全屏 + ✕ 关闭。
**底部**：输入栏（圆角 20px 输入框 + 圆形发送钮，发送中变为方形停止钮）+ 快捷 chips（横向滚动：我的持仓/今日策略/开一笔套利/全托管状态）。

### 2.3 对话流

| 元素 | 规范 |
|---|---|
| AI 气泡 | 左对齐，深卡片底 `#1c2230`，单行高 1.65，最大宽 82% |
| 用户气泡 | 右对齐，绿色半透明底 `rgba(61,220,151,.14)` + 绿描边 |
| 入场 | 250ms 上浮 8px 渐显 |
| 打字指示 | 三点闪烁（1.2s 循环，逐点延迟 0.2s） |
| 时间戳 | 9px 弱化色，气泡右下 |

### 2.4 三闸建议卡（浮窗内可完成批准）

沿用 M-D4 预览卡，紧凑版：

```
策略: 现货×永续 正向套利
标的/名义: XRPUSDT · 15U
白名单闸 ✓ · Jev 复核 ✓ P=0.71 把握度 0.42 · 风控闸 ✓ 7/7
[✓ 批准执行] [✕ 拒绝]
```

批准/拒绝后卡片原地变为执行结果（留痕 ID + 成交价），不再弹额外弹窗。

## 三、状态机

```
FAB(收起) ──点击──▶ 浮窗展开(66%) ──✕/遮罩──▶ FAB(收起)
    ▲                    │
    └──切页（任意 tab）───┘  对话流/滚动位置/输入内容 全部保持
                    │
                    ├──⤢ 全屏──▶ AI 全屏页（完整功能，返回后浮窗状态仍在）
                    └──下拉抓手/键盘收起 ──▶ 浮窗收起（对话保留在内存）
```

**关键不变量**：浮窗与对话流是 App 全局单例（挂在 body 级 DOM），页面切换只影响 `.pages` 层——**切页零刷新、零丢失**。

## 四、对话持久化

| 场景 | 方案 |
|---|---|
| 切页（内存级） | 全局单例 DOM，不销毁——天然保持 |
| 刷新/重进（会话级） | `/api/ai/history?session=global` 从服务端回放（ai_messages.jsonl） |
| 跨端（多设备） | 服务端会话 ID 绑定，登录后拉取最后 50 条 |

## 五、与现有 AI 屏的关系

- **浮窗 = 快速对话层**：问询、看建议、批准/拒绝、快速开平仓
- **AI 屏 = 完整功能页**：我的任务、托管中心、历史记录、套餐升级——浮窗 ⤢ 一键跳转
- 两者共享同一后端 `/api/ai/chat` 流式通道 + 三闸人审流程（M-A/M-D 已上线）

## 七、验收标准

1. 所有页面右下角可见 FAB（行情/交易/持仓/我的/托管中心）
2. 点击展开：动画流畅、菜单栏仍可点击
3. 展开状态切任意页面：浮窗不关、对话不丢、滚动位置保持
4. 浮窗内完成「建议卡→批准→结果留痕」全链路
5. ⤢ 进入全屏 AI 页、返回后浮窗状态仍在
6. 零 JS 错误；Playwright 全路径绿
